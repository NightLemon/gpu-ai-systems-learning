# 数据规模与工程现实

> 大模型不是“找点文本丢进 GPU 就开始训练”。数据获取、清洗、配比、标注、评估和集群工程，本身就是一个复杂系统。

## 预训练数据大概是什么量级

公开信息显示，近几代主流大模型的预训练数据通常已经进入**万亿 token**量级。这个数字的意义不是“越大越一定更好”，而是说明两件事：

- 单靠少量高质量语料不够支撑通用能力
- 数据工程会很快变成系统工程，而不是脚本工程

可以把它粗略理解为：
- 语料来源非常杂，不是单一数据集
- 原始抓取量远大于最终可用量
- 训练集不是一次性整理好后永久不变，而是持续迭代

## 数据通常从哪里来

对通用大模型，预训练数据通常来自多类来源的混合，而不是某一个“神奇数据集”：

- 网页抓取数据
- 代码仓库
- 书籍和长文档
- 百科、问答、论坛、技术文档
- 学术论文和结构化知识源
- 多语言公开文本

其中网页抓取往往占很大比例，因为规模最大，但也是噪声最多、清洗最重的一类来源。

## 真正困难的是把原始数据变成训练数据

从原始网页或原始文档到最终训练样本，中间通常要经过一整条数据处理流水线：

```
原始抓取 / 原始文件
  ↓
正文提取与格式规范化
  ↓
语言识别与编码清理
  ↓
去重
  ↓
质量过滤
  ↓
安全与合规过滤
  ↓
采样、配比、分片
  ↓
最终训练语料
```

这里每一步都可能直接影响模型质量，甚至影响训练是否值得继续烧算力。

## 去重为什么重要

互联网文本天然存在大量转载、镜像、模板页和聚合页。不做去重，至少会带来三个问题：

- 白白消耗训练算力
- 让模型过度记忆重复内容
- 扭曲数据分布，让少数来源被过度放大

常见去重层级包括：

1. **精确去重**：去掉完全重复的样本
2. **近似去重**：去掉只改了少量词句的相似样本
3. **长段重复检测**：处理跨文档复用的大段内容

这类处理在万亿 token 规模下，已经不再是简单文本脚本，而是数据系统问题。

## 质量过滤为什么是核心竞争力

“数据多”不等于“数据好”。很多团队的差异不在模型结构，而在数据筛选标准上。

常见方法有三类：

### 1. 规则过滤

例如过滤：
- 过短文本
- 特殊字符比例异常的文本
- 导航页、广告页、SEO 垃圾页
- 编码错误或明显损坏的内容

### 2. 分类器打分

训练一个小模型，判断文本更像高质量内容还是低质量噪声，再据此过滤或重采样。

### 3. 语言模型分数

使用已有模型的困惑度或类似质量指标，对文本可读性和分布合理性做粗筛。

没有任何一种方法是万能的。实际工程里通常是多种策略叠加，再配合人工抽样验证。

## 数据配比会直接影响模型能力分布

即使同样是“万亿 token 训练”，不同来源的比例也会明显影响结果：

- 代码比例更高，编程能力通常更强
- 多语言比例更高，非英语能力通常更强
- 教科书、文档、论文比例更高，风格和知识分布会变化
- 训练后期重新调整采样比例，会改变模型最后阶段重点学习的东西

所以模型训练不是只有“多大模型、多少卡、跑多久”，还包括“到底喂了什么、按什么比例喂”。

## 后训练数据和预训练数据不是一回事

预训练数据解决的是“模型会不会”，后训练数据更多解决的是“模型怎么表现出来”。

常见后训练数据包括：

- **SFT 数据**：指令-回答、对话、工具使用、多轮任务样本
- **偏好数据**：哪个回答更好、为什么更好
- **安全数据**：攻击样本、拒答样本、边界样本
- **评估数据**：用来判断版本优劣，而不是直接训练

规模上，后训练数据通常远小于预训练数据，但它对产品可用性、稳定性和安全性影响很大。

## 工程上真正要投入哪些能力

一家做通用模型的团队，通常至少需要下面几类工程能力：

- 数据获取与数据管线
- 清洗、去重、质量工程
- 标注与评估平台
- 训练框架与分布式系统
- GPU 集群、网络、存储与调度
- 推理部署与服务优化
- 安全、合规和发布流程

这里面和本仓库最直接相关的是后面三类，也就是系统层面的工程问题。

## 对系统工程来说，最现实的难点是什么

从系统角度看，数据和训练并不难在“知道概念”，而难在“长时间稳定地跑”：

- 数据处理链条很长，任何一步出错都可能污染训练集
- 大规模训练作业运行时间长，必须能 checkpoint、恢复和追踪异常
- 多卡多机训练强依赖通信效率和网络拓扑
- 训练数据读取、checkpoint 写入、评估作业会一起争用存储系统
- 版本迭代要求你能重复构建、重复评估，而不是一次跑通就结束

## 一个更稳妥的时间观

真实世界里，训练一代模型并不是“把 GPU 开起来等几个月”这么简单。通常会并行发生下面几类工作：

- 数据源更新和清洗规则调整
- 小规模消融实验和超参数试验
- 大规模预训练作业
- 后训练和安全迭代
- 推理优化和发布准备

所以一个模型版本的交付周期，往往由数据、实验、评估、部署共同决定，而不只是由预训练时长决定。
